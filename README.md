# Data-201-Project1
Describing the project and main finding:  

Goal: Test if my chosen predictor variables (age, maximum heart rate, chest pain) contribute to the presence/absence of heart disease in the cases in the heart dataset using Log reg, LDA, QDA, KNN. 

Main finding: Log Reg and LDA produced very similar results, however Log Reg won as the chosen model because it beats LDA for accuracy. This metric is prioritized because the .4 threshold pushes the model to find sick patients.
